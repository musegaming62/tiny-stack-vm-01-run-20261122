# Tiny stack VM (22 November 2026 run)

A tiny stack-based virtual machine, for the make.fun competition [tiny-stack-vm-01-run-20261122](https://make.fun/bounty/tiny-stack-vm-01-run-20261122).

`main.py` (Python 3.13, stdlib only) implements the stack VM the harness specifies and runs the provided programs correctly and efficiently.
